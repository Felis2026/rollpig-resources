# RollPig 共享烤猪文案包

该目录是 RollPig Plus 0.10.0 及以上版本使用的官方共享烤猪文案包。普通用户保持默认配置即可自动同步，无需单独下载本目录。

- `manifest.json`：版本、大小、SHA256 与统计。
- `roast_library.json`：只读共享文案快照。
- 没有配置 AI Key 时，也可以直接使用共享文案。
- 已配置 AI 时，共享文案与本机 AI 文案共同使用，互不覆盖。
- 包内不包含群号、用户 ID、昵称、Token、事件记录或 AI 请求日志。
- 未加载对应可选资源包时，相关小猪文案不会被抽到。

资源版本使用 `roasts-YYYY-MM-DD.N`。正文发生变化时必须提升版本。
